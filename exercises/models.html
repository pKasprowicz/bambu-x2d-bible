Test models gallery

Fourteen small, parametric OpenSCAD models that answer one question each: how accurate is my printer, how far can it bridge, how hot should I print this filament? Every file is plain text, uses no external libraries and starts with a comment block that lists its parameters and which exercises use it.

All levels14 .scad fileseach prints in about 5–90 min

How to use these files

OpenSCAD is a free program in which a model is defined by code. That makes the files tiny, easy to adapt (change a number, press render) and easy to share. You do not need to understand the code to use a model: the first lines of each file are the parameters you can change.

  1. Download the .scad file with the link below its preview (or right-click → save link as).
  2. Open it in OpenSCAD (or any compatible editor). Press F5 for a quick preview.
  3. Edit parameters at the top of the file, such as size or start_temp. Preview again.
  4. Render with F6, then export as STL or 3MF (File → Export). Rendering text and many holes can take a few seconds.
  5. Slice and print with the settings recommended in each section, and use the exercise that goes with the model.
No OpenSCAD? No problem

Rendering is only needed to produce an STL. If you cannot install OpenSCAD, ask a friend to export the files once, or recreate the simple shapes in your CAD tool from the dimensions in each section. Several models also need only a few primitives (blocks, cylinders).

🧪 The models

1 · Calibration cube

Purpose: Check dimensional accuracy in X, Y and Z with calipers, spot elephant foot, ringing and layer quality in one 20-minute print. The engraved letters X, Y, Z help you tell the faces apart when you compare notes.

  • Parameters: size (20 mm), letter_h, engrave depth, optional bottom chamfer.
  • Print: 0.2 mm layers, 2–3 walls, 15 % infill, no supports. Measure after the part cools.
  • Read the result: Within ±0.1 mm is a good result for an FDM printer; an error that is consistent suggests a scale or flow correction, while an error only on one axis points to the mechanics.
⬇ calibration_cube.scadExercise L1-2

2 · Temperature tower

Purpose: Find the temperature that gives the best combination of surface, strength and stringing for a new spool, in a single print.

  • Parameters: start_temp (220, the bottom tier), step (5 °C drop per tier), tiers (7); each tier has an engraved temperature, a bridge opening and a 45° overhang fin.
  • Print: Change the nozzle temperature in the slicer at each tier boundary (a temperature-calibration tool in the slicer can do this for you). Adjust start and step for the material: for example start at 260 °C with a 5 °C step for PETG.
  • Read the result: Compare bridges, overhangs and stringing per tier; also try to break the tiers by hand: layer bonding gets better with temperature.
⬇ temp_tower.scadExercise L2-1Exercise L1-11

3 · Bridge test

Purpose: Find the maximum reliable unsupported span for your material, speed and fan setting.

  • Parameters: spans list (10–50 mm), pillar_h, deck_t, depth.
  • Print: 0.2 mm layers, fan at maximum for PLA, no supports. Run once at the default speed and once with a slower bridge speed.
  • Read the result: Look at the underside of each deck: smooth and flat is good, sagging strands or a droop are not.
⬇ bridge_test.scadExercise L2-4

4 · Overhang ladder

Purpose: Find the largest overhang angle that prints without support at your cooling and speed settings.

  • Parameters: angles (30–80° from vertical), slope_len, wedge_w.
  • Print: Print without supports. Note the first wedge whose underside is rough or drooping.
  • Read the result: A typical result for PLA with good cooling is a clean surface to about 50–60° from vertical; use your own value as the design limit.
⬇ overhang_ladder.scadExercise L2-5

5 · Tolerance gauge

Purpose: Decide which clearance to design for a press fit, a sliding fit and a loose fit.

  • Parameters: part (plate, pegs or both), peg diameter (8 mm) and a list of clearances from 0 to 0.5 mm.
  • Print: Use the settings you will use for real parts and print both parts in the same orientation. Test the fit after removing all brim and first-layer flare.
  • Read the result: Note the smallest clearance that moves freely (sliding) and the one that needs a light press (snug). Use these numbers in your CAD tables.
⬇ tolerance_gauge.scadExercise L2-6

6 · Hole gauge

Purpose: Measure how much smaller than nominal printed holes come out, using drill bits or pin gauges, and derive a compensation per diameter.

  • Parameters: diameters (3, 4, 5, 6, 8, 10 mm), optional comp (diameter compensation added to every hole), height, gap.
  • Print: The block has a row of vertical holes and a row of horizontal holes (axis along Y), so one print compares both. Print it with your normal profile.
  • Read the result: Try drill bits or pins: the largest bit that fits is your measure. Typical shrinkage is 0.1–0.3 mm, but depends on printer and material.
⬇ hole_gauge.scadExercise L2-6Project L4-5

7 · Retraction test

Purpose: Judge stringing quickly, and compare retraction length, speed and temperature settings with one plate.

  • Parameters: towers (4), tower_d (8 mm), tower_h (40 mm), spacing (30 mm).
  • Print: Change one retraction value per print (for example 0.4, 0.8, 1.2 mm on a direct-drive extruder). Dry the filament first.
  • Read the result: Count the strings between towers for each setting, and keep the lowest retraction that gives a clean print.
⬇ retraction_test.scadExercise L2-2

8 · Flow cube

Purpose: Calibrate the flow ratio (extrusion multiplier) by measuring a wall that is exactly two extrusion lines thick.

  • Parameters: size, height, wall (0.84 mm), bottom (1.0 mm), optional corner_r.
  • Print: Use a slicer profile with 2 walls, no top layers and no infill so the cube prints as a hollow shell, or use vase mode with a line width of 0.84 mm.
  • Read the result: Measure the wall in several places. New flow = old flow × (modeled wall ÷ measured wall). Change flow in small steps (1–3 %).
⬇ flow_cube.scadExercise L2-3

9 · Ringing tower

Purpose: Visualize ringing and compare accelerations, speeds and input-shaping settings.

  • Parameters: width, depth, height (30 × 30 × 50 mm), notch size (notch_w, notch_d), text_h; the notch is cut into the +X face.
  • Print: Print at a fast speed. Repeat at lower acceleration or with input shaping on. Keep the printer on the same surface for all prints.
  • Read the result: Count ripples and measure their spacing with calipers; the spacing together with the print speed gives the ringing frequency (f = v ÷ spacing).
⬇ ringing_tower.scadExercise L3-2

10 · Snap-fit test

Purpose: Test beams of different length and thickness to find out which ones snap repeatedly without breaking.

  • Parameters: part (clip, socket or both), beam_t (1.6), beam_l (14), hook_h (1.0), beam_w, clearance.
  • Print: Print with the layers running along the beam (print the part on its side or flat, never standing). Use PETG or nylon for repeated use.
  • Read the result: Count the number of snaps until the first crack; compare with the calculated strain and the allowable strain of the material.
⬇ snap_fit_test.scadExercise L3-5

11 · Hinge test

Purpose: Find the smallest clearance at which a print-in-place hinge moves without breaking loose by force.

  • Parameters: knuckles (5), clearance (0.4), pin_r (2 mm), R, seg, leaf_w.
  • Print: Print flat on the bed with the pin axis along the plate, with no supports in the gaps. Try several clearances in a row.
  • Read the result: The hinge should swing through 180° after a first firm movement. Too tight: fused. Too loose: wobble.
⬇ hinge_test.scadExercise L3-4

12 · Text label test

Purpose: Find the smallest readable raised or engraved text for your nozzle, layer height and orientation.

  • Parameters: sizes list (3–10 mm), sample text, bold, relief (0.6 mm), plate_t.
  • Print: Print twice: raised and engraved. Use a bold font. OpenSCAD needs a font (Liberation Sans is bundled with most installations).
  • Read the result: Raised text is generally more readable than engraved text at small sizes; note the smallest row you can read at arm's length.
⬇ text_label_test.scadExercise L2-10

13 · Cable clip

Purpose: A first useful print: tidy a cable on a desk or wall, and practice measuring and adapting a parametric design.

  • Parameters: cable_d (5 mm), fit (0.3), wall (2.4), opening, width, foot_w, screw_d.
  • Print: Lay the clip on its side so that the ring layers run around the cable, in PLA or PETG, 3 walls.
  • Read the result: The cable should snap in with a light push and hold without sliding. Adjust fit and opening for thicker or thinner cables.
⬇ cable_clip.scadExercise L1-9

14 · Parametric box

Purpose: A ready-made parametric project that you can adapt for electronics, tools and gifts, and a reference solution for the CAD exercise.

  • Parameters: inner width, depth and height, wall thickness, lid lip, clearance, part (base, lid, both or preview).
  • Print: Export base and lid separately, each with the largest flat face on the plate. Print the lid first to check the fit.
  • Read the result: The lid should press on with light force and not rattle; change the clearance by 0.05 mm steps.
⬇ parametric_box.scadExercise L2-7

Suggested print order for a new printer

You do not have to print everything. This sequence builds on itself and gives you a complete picture of a new printer or filament in about a day of printing time:

  1. Calibration cube (20 min): sanity check of size and first layer.
  2. Temperature tower (about 1 h): choose the temperature.
  3. Flow cube (15 min): set the flow ratio at that temperature.
  4. Retraction test (30 min): remove stringing.
  5. Bridge test and overhang ladder (about 1 h in total): learn the limits of the cooling.
  6. Tolerance and hole gauges (30 min each): create your clearance table.
  7. Ringing tower (45 min): tune acceleration and input shaping.
Keep the results

Write the numbers into your journal (template on the exercises overview). A table with “filament, temperature, flow, retraction, clearance” saves you from repeating the tests every time.
